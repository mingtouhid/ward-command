# Ward Sync R1.7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the approved R1.7 intern Home, intern tasks, advisory discharge review, and scheduled-ECT completion on a branch without merging, deploying, or migrating production.

**Architecture:** Pure `r17*` rules live in one marked block inside `index.html` and are the only logic the unit tests execute. Screens call those functions. Postgres functions enforce the same boundaries for tasks, ECT occurrence completion, and the discharge audit. The PWA stays one file.

**Tech Stack:** Existing single-file PWA (`index.html`), `sw.js` cache name, SQL migrations with rollback, Node's built-in test runner.

## Global Constraints

- Baseline `d252785` / R1.6.2. Version string `R1.7`. Cache `ward-sync-pwa-r1.7`.
- Do not merge `main`, deploy, or apply migrations.
- Do not implement fixed resident bed assignments.
- Do not grant interns MSE or discharge access, and do not put resident `tasks` on the intern read model.
- Do not call `markEctDone` from the home schedule control, and do not change `next_session_at` or `sessions_done` there.
- Queued vitals are not completed. Deleted and prior-admission MSE/reports are not eligible. Prepared discharge MSE is not eligible until an atomic save returns.
- A saved report does not mean every investigation is complete.
- Synthetic fixtures only. Do not commit screenshots, patient data, secrets, or `/tmp`.
- IST day is `UTC+05:30`, independent of the host timezone.
